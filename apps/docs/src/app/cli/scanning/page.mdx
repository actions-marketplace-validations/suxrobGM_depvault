# Scanning

`depvault scan` checks a repository in one pass: secrets hardcoded in source, vulnerable dependencies, and secret files that aren't in DepVault yet. It reports only — it never uploads files.

```bash
depvault scan [--path <dir>] [--project <id>] [--fail-on <severity>] [--json]
```

| Flag        | Description                                                                 | Default               |
| ----------- | --------------------------------------------------------------------------- | --------------------- |
| `--path`    | Repository root.                                                            | Current repo          |
| `--project` | Project ID.                                                                 | From `.depvault.json` |
| `--fail-on` | Exit with code `4` when a leak or vulnerability is at least `low`, `medium`, `high`, or `critical`. | `none` |
| `--json`    | Print the full report as JSON.                                              |                       |

---

## What it checks

1. **Secret leaks** — scans source files locally for hardcoded secrets (cloud keys, private keys, API tokens, connection strings). Matches are shown by their first four characters only, so the secret never lands in your terminal or CI logs. Interactively, `scan` offers to add the offending files to `.gitignore`.
2. **Dependencies** — analyzes every dependency file (`package.json`, `requirements.txt`, `*.csproj`, …) and shows health scores and vulnerability counts. See [Dependency Analysis](/guides/dependency-analysis).
3. **Secret files** — lists git-ignored secret files that aren't in DepVault yet. Store them with `depvault push`, or skip one for good with `depvault untrack <path>`.

Steps 2 and 3 need the server, so they run only when you're logged in and the folder is [linked](/cli/sync#link-a-repo-depvault-init). Otherwise — for example in CI — `scan` checks for leaked secrets only.

---

## As a CI gate

The leak check runs locally and needs no token, so it works in any pipeline:

```yaml
- name: Check for leaked secrets
  run: depvault scan --fail-on high
```
