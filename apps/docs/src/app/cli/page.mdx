# CLI

The DepVault CLI (`depvault`) syncs your repo's secret files and analyzes dependencies. It's a single self-contained native binary (.NET 10 Native AOT) with no runtime dependencies.

---

## Installation

### Quick Install

**Linux / macOS:**

```bash
curl -fsSL https://get.depvault.com | bash
```

**Windows (PowerShell):**

```powershell
irm https://get.depvault.com | iex
```

The installer detects your platform, downloads the latest release to `~/.depvault/bin/`, and adds it to PATH. Set `DEPVAULT_INSTALL_DIR` to install elsewhere. Run `depvault update` later to upgrade in place.

### Manual Download

Pre-built binaries are on the [GitHub Releases](https://github.com/suxrobGM/depvault/releases) page:

| Platform | Archive |
| --- | --- |
| Linux x64 | `depvault-linux-x64.tar.gz` |
| Linux ARM64 | `depvault-linux-arm64.tar.gz` |
| macOS x64 | `depvault-osx-x64.tar.gz` |
| macOS ARM64 | `depvault-osx-arm64.tar.gz` |
| Windows x64 | `depvault-win-x64.zip` |

### Build from Source

Requires the [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

```bash
git clone https://github.com/suxrobGM/depvault.git
cd depvault/apps/cli
dotnet publish -c Release -r <rid>   # linux-x64, linux-arm64, osx-x64, osx-arm64, win-x64
```

## First Run

```bash
depvault login     # browser sign-in
cd my-repo
depvault init      # link the repo to a project, writes .depvault.json
depvault push      # upload the repo's secret files
```

Run `depvault doctor` any time: it checks the server, login, vault, project link, and encryption key, and prints the exact command to fix anything missing.

## Commands

| Command | Description |
| --- | --- |
| `depvault login` / `logout` / `whoami` | [Sign in](/cli/authentication) with the browser device flow |
| `depvault unlock` / `lock` | [Unlock the vault](/cli/authentication#unlocking-the-vault) on this device, or forget it |
| `depvault init` | [Link this folder](/cli/sync#link-a-repo-depvault-init) to a project |
| `depvault status` | [Show what differs](/cli/sync#depvault-status) from DepVault |
| `depvault push` | [Upload local changes](/cli/sync#depvault-push) |
| `depvault pull` | [Download server changes](/cli/sync#depvault-pull) (also the CI command) |
| `depvault untrack` | [Stop syncing a file](/cli/sync#depvault-untrack) |
| `depvault purge` | [Delete local copies](/cli/sync#depvault-purge) of synced files |
| `depvault project` | Show the linked project and list your projects |
| `depvault analyze` | [Analyze dependency files](/guides/dependency-analysis) |
| `depvault scan` | [Scan the repo](/cli/scanning) for vulnerabilities, leaks, and unsynced secret files |
| `depvault doctor` | Diagnose setup and print next steps |
| `depvault config` | Show or change `server` and `output` (`config set <key> <value>`, `config get <key>`) |
| `depvault update` | Update the CLI to the latest release |
| `depvault version` | Print the CLI version |

Run `depvault <command> --help` for every flag.

## Interactive Mode

Run `depvault` with no arguments for a session with a status line (folder, repo, account, vault state, linked project). Type commands with or without a leading `/`; `Tab` autocompletes, `help` lists commands, and `exit` quits.

---

## Configuration

Settings are per machine; the project is per repo (`.depvault.json`).

```bash
depvault config set server https://depvault.example.com
depvault config set output json     # default output for list commands
```

| Variable | Purpose |
| --- | --- |
| `DEPVAULT_TOKEN` | CI token; switches the CLI to [CI mode](/guides/ci-cd-integration) |
| `DEPVAULT_PASSWORD` | Vault password for non-interactive use as yourself |
| `DEPVAULT_HOME` | CLI config folder (default `~/.depvault`) |
| `DEPVAULT_INSTALL_DIR` | Install location for the install script |

## Changes in the sync release

The file model is now path-only, so these were removed: `depvault ci pull` (use `depvault pull` with `DEPVAULT_TOKEN`), `project select/create/info` and `config set project` (use `depvault init`), the `--app`, `--environment`, `--include-base`, `--include-secrets`, `--output-dir`, and `--format` flags, `unlock --remember/--ttl`, and the upload steps in `scan`.
