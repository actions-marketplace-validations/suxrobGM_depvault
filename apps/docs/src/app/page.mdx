# DepVault Documentation

DepVault keeps your repo's secret files in sync across machines and pipelines with end-to-end encryption, and analyzes your dependencies for vulnerabilities, outdated packages, and license issues.

## What is DepVault?

- **Encrypted file sync** — Store the files you keep out of git (`.env`, `appsettings.Development.json`, keys, credentials) by their repo path, with full version history. `depvault push` and `depvault pull` work like git; the web app lets you browse, edit, and restore them.
- **CI/CD without copy-paste** — Pipelines run `depvault pull` with a read-only, path-scoped token instead of pasting whole `.env` files into CI secrets.
- **Sharing** — Send a file through a one-time encrypted link; share project access with teammates.
- **Dependency analysis** — Scan dependency files from 9 ecosystems for known CVEs, outdated versions, and license conflicts, and scan git history for leaked credentials.

## Why DepVault?

Files are encrypted in your browser or the CLI before they leave your device. Your vault password never leaves it, and the server stores only ciphertext it can't decrypt. The full codebase is open source, so you can audit every line. See [Encryption & Security](/guides/encryption).

## Quick Start

```bash
depvault login
cd my-repo
depvault init     # link the repo, commit the generated .depvault.json
depvault push     # upload the repo's secret files
```

On another machine or a teammate's checkout: `depvault pull`.
