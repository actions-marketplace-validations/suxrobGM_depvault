# Getting Started

## Create Your Account

Register with email and password (verify the link sent to your inbox), or click **Continue with GitHub** on the login page.

---

## Set Up Your Encryption Vault

Before you can store files in the web app or the CLI, set up your vault in the web dashboard under **Profile → Security**:

1. Choose a **vault password**. It's separate from your login password and **never leaves your device**.
2. Save the **recovery key** shown once. It's your only way back in if you forget the vault password; keep it offline.

DepVault can't reset your vault password or recover your data. If you lose both the password and the recovery key, the data is gone. See [Encryption & Security](/guides/encryption).

---

## Install the CLI

```bash
# Linux / macOS
curl -fsSL https://get.depvault.com | bash

# Windows (PowerShell)
irm https://get.depvault.com | iex
```

---

## Sync Your First Repo

```bash
depvault login        # opens the browser
cd my-repo
depvault init         # pick or create a project; writes .depvault.json
depvault status       # see what will be uploaded
depvault push         # upload (asks for your vault password once per device)
git add .depvault.json && git commit -m "Link DepVault"
```

`depvault push` offers your git-ignored secret files (`.env*`, `appsettings*.json`, `*.pem`, `credentials.json`, …). Track anything else by naming it: `depvault push path/to/file`. If something isn't set up, run `depvault doctor`; it prints the exact command to run next.

On another machine, or for a teammate who clones the repo:

```bash
depvault login
depvault pull
```

From then on it's the usual loop: edit a file, `depvault push`; `depvault pull` to get others' changes. See [File Sync](/cli/sync).

---

## Use the Web App

Open the project and go to the **Files** tab to browse the folder tree, drop in files, edit `.env` files as key/value forms, compare and restore versions, and download everything as a zip. See [Files](/guides/files).

---

## Restore Files in CI

Create a CI token under **Settings → CI/CD Tokens**, store it as `DEPVAULT_TOKEN`, and run `depvault pull` in the pipeline. See [CI/CD Integration](/guides/ci-cd-integration).

---

## Run a Dependency Scan

- **Web:** open the project, go to **Analysis**, click **New Analysis**, and upload a dependency file (`package.json`, `requirements.txt`, `Cargo.toml`, …).
- **CLI:** `depvault analyze` in the repo, or `depvault scan` for dependencies, leaked secrets, and unsynced secret files in one pass.

See [Dependency Analysis](/guides/dependency-analysis).
