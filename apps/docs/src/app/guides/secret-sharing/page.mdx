# Secret Sharing

Send a single file to a teammate or an outside collaborator with a one-time, end-to-end encrypted link.

---

## How It Works

1. Your browser encrypts the file with a fresh one-time key. The key goes in the link's URL fragment (`#key=…`), which never reaches the server.
2. You send the link.
3. The recipient opens it, enters the password if you set one, and sees the decrypted file.
4. The encrypted copy is **permanently deleted** after the first access, or when the link expires — whichever comes first.

---

## Create a Link

1. In the project's **Files** tab, open the file.
2. Choose **File actions** → **Share via one-time link**.
3. Pick **Link expires after** (1 hour, 24 hours, or 7 days) and optionally **Password protect this link**.
4. Click **Generate Link** and copy the URL.

The link shares the file's current contents; later edits don't change it.

---

## Recipient Experience

The recipient opens the link, enters the password if required (wrong attempts don't consume the link), and views the content. Once viewed, it's gone — they should copy what they need before leaving the page.

---

## Track and Revoke Links

All of a project's links are listed under **Settings** → **Share Links**, where you can revoke any pending link.

| Status | Meaning |
| --- | --- |
| **PENDING** | Created, not yet opened. |
| **VIEWED** | Opened by the recipient. Content destroyed. |
| **EXPIRED** | Expired unopened. Content destroyed. |

Creation, views, and expiry are recorded in the project's activity log — never the content.
